# Модуль: Структури даних і алгоритми на C++

Модуль для курсу C++ / MilTech: класичні структури даних і алгоритми,
але на прикладах з дронів — телеметрія, планувальник задач автопілота, таблиця параметрів,
планування маршруту в обхід заборонених зон, контрольна сума MAVLink.

**Мета:** студент розуміє, *чому* обирати саме цю структуру (складність + пам'ять + кеш),
вміє реалізувати базові структури сам і знає, що вже є в STL.

## Швидкий старт

Потрібні тільки `g++` (або `clang++`) з C++17 і `cmake` ≥ 3.16. Сторонніх бібліотек немає.

**WSL Ubuntu / Linux / macOS terminal:**

```bash
cd dsa-cpp-module/code
./scripts/test.sh            # збірка + усі тести
./build/05_route_planner     # будь-який приклад
./scripts/test.sh T04        # тести тільки однієї задачі
./scripts/build.sh asan      # збірка з AddressSanitizer — ловить вихід за межі масиву
```

Очікувано на старті: `12/12` лекційних тестів зелені, `0/14` тестів задач — червоні.
Робота студента — зробити `14/14`.

## Зв'язок з модулем ArduPilot

`05_route_planner` записує `route.csv` з координатами waypoint'ів навколо home SITL.
Додаткова задача E1 у `06_zadachi.md` — підставити цей маршрут у C++/MAVSDK програму з
модуля ArduPilot і пролетіти його в SITL, бачачи траєкторію в Mission Planner.

## Що перевірено

- Збірка g++ 15, C++17, `-Wall -Wextra -Wpedantic` — без попереджень.
- `test_lecture` 12/12, `test_tasks` з розв'язками 14/14; ті самі тести під ASan + UBSan — чисто.
- Усі 6 прикладів запускаються; цифри в `.md` — з реального запуску (на іншій машині час буде інший,
  співвідношення — ті самі).
