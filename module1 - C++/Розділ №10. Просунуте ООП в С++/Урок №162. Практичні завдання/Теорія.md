## Рівень 1. Створення простого класу

### Завдання

Створіть клас `Student`:
- `private` поля: `name` (string), `age` (int), `grade` (double);
- конструктор з параметрами (використовуйте список ініціалізації);
- геттери: `getName()`, `getAge()`, `getGrade()`;
- сеттер `setGrade(double)` з валідацією (значення від 2 до 12);
- метод `printStudent()`.

У `main()` створіть 3 студенти, виведіть їх, потім змініть одній оцінку і виведіть ще раз.

### Очікуваний результат

```
Student: Oleg, age 20, grade 10.5
Student: Anna, age 19, grade 11.2
Student: Ivan, age 21, grade 8.5
(після зміни) Student: Ivan, age 21, grade 9.5
```

## Рівень 2. Наслідування

### Завдання

Створіть базовий клас `Person`:
- `protected` поля: `name`, `age`;
- конструктор зі списком ініціалізації;
- метод `introduce()` — виводить «Мене звати <name>, мені <age> років».

Створіть нащадок `Teacher`:

- перевизначений метод `introduce()`, який додає «Я викладаю <subject>».

У `main()` створіть об'єкти обох класів і викличте `introduce()`.

### Очікуваний результат


## Рівень 3. Наслідування з конструкторами

### Завдання

Створіть таку ієрархію:

```
    Device
      ↓
   Computer
      ↓
    Laptop
```

- `Device` — `protected` поле `brand`, конструктор `Device(string)`;
- `Computer` — `protected` поле `ramGb` (int), конструктор `Computer(string, int)` який викликає `Device(brand)`;
- `Laptop` — `private` поле `weightKg` (double), конструктор `Laptop(string, int, double)`.

Кожен конструктор виводить своє повідомлення, кожен деструктор — своє. Поясніть порядок виклику.

### Очікуваний результат

```
Device constructor
Computer constructor
Laptop constructor
Laptop destructor
Computer destructor
Device destructor
```

## Рівень 7. Мініпроєкт «Бібліотека»

### Завдання

Створіть маленьку систему бібліотеки з:

1. Базовий абстрактний клас `LibraryItem`:
   - `private` поля: `title`, `id`;

## Підсумковий чек-лист

Після виконання всіх рівнів ви маєте вміти пояснити:

| Концепція | Де я використав? |
| --------- | ---------------- |
| Інкапсуляція | `private` поля + геттери/сеттери |
| Наслідування | класи-нащадки базового класу |
| Поліморфізм | виклик методів через `BaseClass*` |
| Абстракція | чисто віртуальні методи |
| Композиція | клас, що містить інший об'єкт |
| Віртуальний деструктор | правильне звільнення пам'яті |

Якщо можете пояснити кожен рядок — ви готові писати власні ООП-системи.
