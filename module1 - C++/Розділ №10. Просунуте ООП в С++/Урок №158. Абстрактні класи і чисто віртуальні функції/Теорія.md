# Урок №158. Абстрактні класи і чисто віртуальні функції

## 1. Чисто віртуальна функція

У базовому класі іноді бажано визначити **метод, який обов'язково мають реалізувати всі нащадки**, але сам базовий клас не знає, як це робити.

Для цього використовується **чисто віртуальна функція** — віртуальна функція без реалізації:

```c++
virtual void makeSound() = 0;
```

Що означає `= 0`? Це «нульове призначення» (pure specifier). воно каже: «цей метод не має реалізації в базовому класі — кожен нащадок ЗОБОВ'ЯЗАНИЙ надати свою».

## 2. Абстрактний клас

**Абстрактний клас** — клас, що містить хоча б одну чисто віртуальну функцію.

Ключова властивість: **об'єкт абстрактного класу неможливо створити**.

```c++
class Animal {
public:
    virtual void makeSound() = 0;   // чисто віртуальна
};

// Animal animal;   // ❌ ПОМИЛКА: Animal — абстрактний клас
```

**Чому**: абстрактний клас — це «шаблон для шаблону». Він описує **що** потрібно робити, але не **як**. Тому створювати його об'єкт немає сенсу — він неповний.

## 3. Дочірній клас реалізує чисто віртуальний метод

```c++
class Dog : public Animal {
public:
    void makeSound() override {   // обов'язково реалізуємо!
        cout << "Woof!\n";
    }
};

class Cat : public Animal {
public:
    void makeSound() override {
        cout << "Meow!\n";
    }
};
```

Тепер `Dog` і `Cat` — **конкретні класи** (не абстрактні), бо вони реалізували всі чисто віртуальні методи. Їхні об'єкти можна створювати.

```c++
Dog dog;   // ✅ Dog не абстрактний
Cat cat;   // ✅ Cat не абстрактний
```

## 4. Повний приклад

```c++
#include <iostream>
#include <string>
using namespace std;

class Animal {
protected:
    string name;

public:
    Animal(string name) : name(name) {}
    virtual void makeSound() = 0;

    virtual ~Animal() {}
};

class Dog : public Animal {
public:
    Dog(string name) : Animal(name) {}

    void makeSound() override {
        cout << name << ": Woof!\n";
    }
};

class Cat : public Animal {
public:
    Cat(string name) : Animal(name) {}

    void makeSound() override {
        cout << name << ": Meow!\n";
    }
};

int main() {
    // Animal a("X");       // ❌ Animal абстрактний

    Dog dog("Rex");
    Cat cat("Barsik");

    Animal* animals[] = { &dog, &cat };

    for (int i = 0; i < 2; i++) {
        animals[i]->makeSound();
    }
    return 0;
}
```

Результат:
```
Rex: Woof!
Barsik: Meow!
```

## 5. Абстракція + поліморфізм: чому це потужно

```
             Animal
          abstract class
               │
       ┌───────┴───────┐
       ↓               ↓
      Dog             Cat
       │               │
    makeSound()     makeSound()
    "Woof!"          "Meow!"
```

Переваги:

1. **Єдиний інтерфейс**: весь код працює з `Animal*` або `Animal&` і не знає про конкретні типи.
2. **Розширюваність**: можна додати нову тварину (наприклад, `Duck`), не змінюючи існуючий код.
3. **Вимога реалізації**: компілятор змушує кожен нащадок реалізувати `makeSound()` — забути неможливо.

## 6. Кілька чисто віртуальних функцій

```c++
class Shape {
public:
    virtual double area() = 0;
    virtual string getName() = 0;
    virtual ~Shape() {}
};

class Circle : public Shape {
private:
    double radius;
public:
    Circle(double r) : radius(r) {}

    double area() override { return 3.14159 * radius * radius; }
    string getName() override { return "Circle"; }
};
```

Якщо нащадок **не** реалізує хоча б одну з чисто віртуальних функцій — він теж стає абстрактним:

```c++
class HalfCircle : public Shape {
public:
    double area() override { return 1.5708 * radius * radius; }
    // getName() НЕ реалізовано → HalfCircle лишається абстрактним!
};
```

## 7. Коли використовувати

- Коли базовий клас описує **інтерфейс** («що вміють тварини»), а реалізацію визначають нащадки;
- Коли хочете гарантувати, що кожен нащадок матиме певний набір методів;
- Коли не хочете створювати об'єкти базового класу, бо він неповний.

## 8. Типові помилки

**Помилка 1: забули реалізувати чисто віртуальний метод**
```c++
class Dog : public Animal {
public:
    Dog(string name) : Animal(name) {}
    // makeSound() НЕ реалізовано → Dog абстрактний!
};
// Dog dog("Rex");  // ❌ не можна створити!
```

**Помилка 2: спроба створити об'єкт абстрактного класу**
```c++
Animal a("X");   // ❌ Animal абстрактний (має = 0 метод)
```
