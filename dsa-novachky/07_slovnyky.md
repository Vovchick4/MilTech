# Урок 7. Словники: `std::map`

## Що вивчимо

- Як зберігати пари «ключ → значення» (ім'я параметра → його значення).
- Як рахувати, скільки разів щось зустрічається.
- Чим `std::map` відрізняється від `std::unordered_map` і де пастка з `[]`.

## Навіщо дрону

В автопілоті ArduPilot понад тисячу параметрів: `WPNAV_SPEED`, `RTL_ALT`, `BATT_CAPACITY`...
Шукати параметр за іменем у звичайному масиві — перебирати всі (O(n)).
Словник знаходить значення за ключем **одразу**.

## Ідея: телефонна книга

```
       ключ               значення
  +---------------+    +----------+
  | BATT_CAPACITY | -> |   5200   |
  | FENCE_ENABLE  | -> |      0   |
  | RTL_ALT       | -> |   4000   |
  | WPNAV_SPEED   | -> |   1500   |
  +---------------+    +----------+
```

Не треба знати «номер рядка» — шукаємо одразу за іменем.

## Основні операції

```cpp
#include <map>

std::map<std::string, double> params;   // ключ — рядок, значення — число

params["WPNAV_SPEED"] = 1500;   // додати
params["RTL_ALT"] = 3000;
params["RTL_ALT"] = 4000;       // такий ключ уже є -> значення ЗАМІНЮЄТЬСЯ (не дублюється)

double alt = params["RTL_ALT"]; // прочитати: 4000

if (params.count("FENCE_ENABLE") == 1) { ... }   // чи є ключ? (1 — є, 0 — немає)

params.erase("RTL_ALT");        // видалити
int n = (int)params.size();     // скільки пар
```

Пройти по всіх парам:

```cpp
for (const auto& item : params) {
    std::cout << item.first << " = " << item.second << "\n";
}
```

- `item.first` — ключ, `item.second` — значення.
- `std::map` завжди віддає ключі **за алфавітом** (відсортованими).

## Пастка: `[]` створює ключ!

```cpp
double oops = params["WPNAV_SPED"];   // одруківка в імені
```

Такого ключа немає — і `[]` мовчки **створить** його зі значенням 0. Розмір словника збільшиться,
а помилку ти не помітиш. Приклад показує це наживо:

```
До помилки розмір = 4, після params["WPNAV_SPED"] розмір = 5 (значення 0) — з'явився зайвий параметр!
```

Правило:

| Хочу | Пиши |
|---|---|
| записати / змінити | `params[name] = value;` |
| перевірити, чи є | `params.count(name) == 1` |
| безпечно прочитати | спочатку `count`, потім `params.at(name)` |

`at()` при відсутньому ключі не створює його, а зупиняє програму з помилкою — так одруківку видно одразу.

## Підрахунок — найчастіше застосування

Скільки секунд дрон був у кожному режимі, якщо лог записує режим щосекунди?

```cpp
std::map<std::string, int> seconds_in_mode;
for (int i = 0; i < (int)log.size(); i++) {
    seconds_in_mode[log[i]] = seconds_in_mode[log[i]] + 1;
}
```

Тут `[]` якраз корисний: для нового режиму він створює 0, і ми додаємо 1.

## `std::map` чи `std::unordered_map`?

| | `std::map` | `std::unordered_map` |
|---|---|---|
| Порядок ключів | за алфавітом | довільний |
| Пошук | O(log n) | O(1) в середньому |
| Коли | потрібен порядок (звіт за алфавітом) | лише швидкий пошук |

Використовуються однаково, просто інший `#include` і назва. `unordered_map` всередині — це
**хеш-таблиця**: ключ перетворюється на номер «шафки», де лежить значення
(детально — у модулі рівня 2).

## Перевір себе

1. `params["A"] = 1; params["A"] = 2;` — скільки елементів у словнику і яке значення?
<details><summary>Відповідь</summary>Один елемент, значення 2. Ключі в map унікальні.</details>

2. Чому у функції з `const std::map<...>& params` не скомпілюється `params[name]`?
<details><summary>Відповідь</summary>`[]` може змінити словник (створити ключ), а const це забороняє. Треба count + at.</details>

3. Потрібно надрукувати параметри за алфавітом. map чи unordered_map?
<details><summary>Відповідь</summary>std::map — він тримає ключі відсортованими.</details>

## Коротко

- Словник — пари «ключ → значення», пошук за ключем без перебору.
- `[]` — записати; `count` — перевірити; `at` — безпечно прочитати.
- `std::map` — відсортовано, O(log n). `std::unordered_map` — без порядку, O(1).
