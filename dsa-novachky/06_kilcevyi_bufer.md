# Урок 6. Кільцевий буфер

## Що вивчимо

- Як зберігати **останні N** вимірів, не витрачаючи нову пам'ять.
- Як працює оператор `%` (остача від ділення) для «загортання» індексу.
- Як шукати глітчі (стрибки) датчика за допомогою середнього.

## Навіщо дрону

Датчик висоти (барометр) іноді видає дурниці: висота 30 м, 31 м, **92 м**, 30 м.
Щоб помітити такий стрибок, порівнюємо новий вимір із середнім за останні кілька секунд.
Отже, треба пам'ятати **останні N вимірів**, а старі — забувати.

Можна було б `push_back` у `std::vector` — але він росте нескінченно, а пам'яті на дроні мало.
Рішення — **кільцевий буфер**: масив фіксованого розміру, який записується по колу.

## Ідея: як стрілка годинника

Після 12 годин знову 1 година. Так і індекс запису: після останньої комірки — знову нульова.

```
CAPACITY = 5

push(10)  [10,  _,  _,  _,  _ ]   head -> 1
push(20)  [10, 20,  _,  _,  _ ]   head -> 2
push(30)  [10, 20, 30,  _,  _ ]   head -> 3
push(40)  [10, 20, 30, 40,  _ ]   head -> 4
push(50)  [10, 20, 30, 40, 50 ]   head -> 0   <- «загорнувся» на початок
push(60)  [60, 20, 30, 40, 50 ]   head -> 1   <- 10 (найстаріший) перезаписано
push(70)  [60, 70, 30, 40, 50 ]   head -> 2
```

- `head` — куди писати **наступне** значення.
- `count` — скільки значень реально збережено (росте до CAPACITY і далі не росте).

## Оператор `%` — остача від ділення

```
0 % 5 = 0     5 % 5 = 0   <- ось «загортання»
1 % 5 = 1     6 % 5 = 1
4 % 5 = 4     7 % 5 = 2
```

Тому зсув head на одну позицію вперед по колу:

```cpp
head = (head + 1) % CAPACITY;   // 0,1,2,3,4,0,1,2,...
```

## Код

```cpp
class AltitudeHistory {
public:
    static const int CAPACITY = 5;

    void push(double value)
    {
        data[head] = value;
        head = (head + 1) % CAPACITY;
        if (count < CAPACITY) {
            count = count + 1;
        }
    }

    int size() const { return count; }

    // i = 0 — найстаріший, i = size()-1 — найновіший
    double get(int i) const
    {
        int oldest = (head - count + CAPACITY) % CAPACITY;
        return data[(oldest + i) % CAPACITY];
    }

private:
    double data[CAPACITY] = {0, 0, 0, 0, 0};   // розмір фіксований — пам'ять не росте
    int head = 0;
    int count = 0;
};
```

Нове в цьому коді:

- **`class`** — як `struct`, але частина полів схована (`private`): їх не можна змінити ззовні,
  тільки через методи. Так ніхто випадково не зіпсує `head`.
- **Методи** (`push`, `get`) — функції всередині класу, які працюють з його полями.
- **`const` після методу** (`int size() const`) — метод нічого не змінює в об'єкті.
- **`static const int CAPACITY = 5`** — константа, спільна для класу.

Звідки формула `oldest`? Найстаріший елемент стоїть на `count` позицій «позаду» head.
`+ CAPACITY` додаємо, щоб не вийшло від'ємне число до `%`.

Зверни увагу: «сирий» масив `data` виглядає переплутаним, але `get(i)` завжди віддає
значення в правильному порядку — від найстарішого до найновішого.

## Складність

| Операція | Складність | Чому |
|---|---|---|
| `push` | O(1) | один запис і одне `%` |
| `get(i)` | O(1) | обчислили індекс — і взяли |
| середнє | O(N) | прохід по N збережених |
| пам'ять | завжди N комірок | нічого не виділяється під час польоту |

## Типові помилки

| Помилка | Що буде |
|---|---|
| `head = head + 1` без `% CAPACITY` | вихід за межі масиву після N записів |
| `count = count + 1` без перевірки | `count` росте вище CAPACITY, `get` ламається |
| `(head - count) % CAPACITY` без `+ CAPACITY` | від'ємний індекс |

## Коротко

- Кільцевий буфер — масив фіксованого розміру + індекс `head`, що ходить по колу.
- `head = (head + 1) % CAPACITY` — серце структури.
- push і get — O(1), пам'ять не росте. Це головна структура в коді дронів (телеметрія, радіоканал, датчики).
