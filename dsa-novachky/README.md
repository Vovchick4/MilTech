# Алгоритми і структури даних на C++ — для новачків

Цей модуль для тих, хто вже знає основи C++: змінні, `if`, цикли, функції, `std::vector`,
`std::string`, `struct`. Більше нічого не потрібно — усе нове пояснюється на місці.

Усі приклади — про дрони: висота, заряд батареї, режими польоту, маршрут на карті.

## Як проходити

1. Читай урок (`01_...md`, `02_...md` ...) по порядку.
2. Запускай приклад з уроку і порівнюй з тим, що написано в тексті.
3. Роби вправи у файлі `exercises.cpp` — там, де написано `// TODO`.
4. Запускай вправи, поки всі рядки не стануть `[OK]`.
5. Відповідай на питання «Перевір себе» в кінці уроку (відповіді заховані — спершу подумай сам).

Не поспішай. Краще один урок добре, ніж три — «приблизно».

## Що в папці `code/`

```
code/
├── lesson01/
│   ├── example.cpp      <- приклад з уроку: просто запусти і подивись
│   └── exercises.cpp    <- вправи: тут працюєш ти
├── lesson02/ ... lesson08/   (так само)
├── lesson09/project.cpp <- підсумковий проєкт
└── check_all.sh         <- показати прогрес по всіх уроках одразу
```

## Як запускати

Відкрий термінал (**WSL Ubuntu** на Windows, або термінал на Linux / macOS):

```bash
cd code/lesson02
g++ -std=c++17 -Wall exercises.cpp -o exercises
./exercises
```

Прогрес по всіх уроках:

```bash
cd code
./check_all.sh
```
