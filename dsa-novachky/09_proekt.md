# Урок 9. Підсумковий проєкт: «Бортовий журнал польоту»

## Задача

Дрон злетів, пролетів місію і сів. Його журнал — 20 записів, кожні 5 секунд:

```cpp
struct LogEntry {
    int time;          // секунди від старту
    double altitude;   // висота, м
    int battery;       // заряд, %
    std::string mode;  // режим польоту
};
```

```
time | altitude | battery | mode
   0 |      0.0 |     100 | STABILIZE
   5 |      0.0 |     100 | GUIDED
  10 |      8.0 |      98 | GUIDED
 ...
  40 |     92.0 |      86 | AUTO       <- глітч барометра!
 ...
  95 |      0.0 |      65 | LAND
```

Треба написати 8 функцій, кожна — з одного з уроків, і отримати звіт про політ.

Порядок довільний — починай з того, що найлегше.

## Підказки

- **П3.** Медіана для `{1, 2, 3, 4}` — це (2 + 3) / 2 = 2.5. Зверни увагу, що медіана майже не помічає
  глітч 92 м, а максимум (П1) — саме його і знаходить. Тому для датчиків медіана надійніша.
- **П4.** Це вправа 4.3, тільки порівнюємо `log[mid].time`.
- **П5.** Кладемо режим у стек, тільки якщо він **відрізняється** від того, що на вершині.
  Потім знімаємо все зі стеку — порядок сам розвернеться.
- **П6.** Можна взяти клас з уроку 6 або простіше: вектор з останніми 3 нормальними висотами.
  Глітч у цей вектор не додаємо!
- **П8.** Спочатку двома циклами знайди, де на карті `H` і `D`. Далі — BFS з уроку 8.
