# Урок 2. Масиви: пройти, порахувати, знайти

## Що вивчимо

- Як пройти по масиву і порахувати суму, середнє.
- Як знайти максимум і **номер** максимуму.
- Лінійний пошук: знайти перший елемент, що підходить.

## Навіщо дрону

Дрон раз на секунду записує висоту. Після польоту треба відповісти:
яка була максимальна висота? Коли дрон уперше піднявся вище 25 м? Яка середня висота?

## Масив — ряд пронумерованих шафок

```
індекс:    0     1     2     3      4      5     ...
         +-----+-----+-----+------+------+------+
висота:  | 0.0 | 2.5 | 6.0 | 11.2 | 18.4 | 25.0 | ...
         +-----+-----+-----+------+------+------+
```

- Нумерація **з 0**. Останній елемент — `heights[heights.size() - 1]`.
- Взяти елемент за номером — O(1), миттєво.

## Сума і середнє

```cpp
double sum = 0.0;
for (int i = 0; i < (int)heights.size(); i++) {
    sum = sum + heights[i];
}
double average = sum / heights.size();
```

Покроково для `{2, 4, 9}`:

| i | heights[i] | sum після кроку |
|---|---|---|
| — | — | 0 |
| 0 | 2 | 2 |
| 1 | 4 | 6 |
| 2 | 9 | 15 |

Середнє = 15 / 3 = 5.

> Якщо масив порожній, `size()` = 0 і буде ділення на нуль. Перевіряй `heights.empty()`.

## Максимум і його номер

Згадай алгоритм «найвища людина в кімнаті» з уроку 0:

```cpp
int best = 0;                          // припускаємо, що найбільший — перший
for (int i = 1; i < (int)heights.size(); i++) {
    if (heights[i] > heights[best]) {
        best = i;                      // знайшли більший — запам'ятали ЙОГО НОМЕР
    }
}
```

Чому зберігаємо **номер**, а не значення? Бо з номера можна дізнатися і значення
(`heights[best]`), і **коли** це було (номер = секунда).

## Лінійний пошук

Знайти першу секунду, коли висота стала ≥ 25 м: йдемо зліва направо і зупиняємось на першому, що підійшов.

```cpp
int first_time_above(const std::vector<double>& heights, double limit)
{
    for (int i = 0; i < (int)heights.size(); i++) {
        if (heights[i] >= limit) {
            return i;      // знайшли — одразу виходимо
        }
    }
    return -1;             // пройшли все — не знайшли
}
```

**-1** — домовленість «не знайдено» (бо номер не може бути від'ємним).

Складність — **O(n)**: у найгіршому випадку дивимось усі елементи.

## Типові помилки

| Помилка | Що буде | Як правильно |
|---|---|---|
| `i <= heights.size()` | вихід за межі масиву, програма може впасти | `i < heights.size()` |
| `int best = 0;` для мінімуму значень, а не індексу | якщо всі числа > 0, мінімум «буде» 0 | почни з першого елемента: `int best = values[0];` |
| ділення на `size()` без перевірки | ділення на нуль | `if (v.empty()) return 0;` |
| `return -1` всередині циклу замість після | шукає тільки в першому елементі | `return -1` — **після** циклу |

## Коротко

- Прохід по масиву — цикл `for` від 0 до `size()`, це O(n).
- Максимум/мінімум: «найкращий поки що» + порівняння з кожним.
- Лінійний пошук: йдемо по черзі, повертаємо номер або -1.
