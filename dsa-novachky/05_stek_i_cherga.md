# Урок 5. Стек і черга

## Що вивчимо

- Черга (`std::queue`): хто перший прийшов — той перший вийшов.
- Стек (`std::stack`): хто останній прийшов — той перший вийшов.
- Як вибрати між ними.

## Черга — як у магазині

```
вхід (push) ->  [ LAND | GOTO P2 | GOTO P1 | TAKEOFF | ARM ]  -> вихід (front/pop)
                 останній                              перший
```

**FIFO** — First In, First Out. Команди дрону мають виконуватись у тому порядку, в якому прийшли:
спочатку ARM, потім TAKEOFF, а не навпаки.

```cpp
#include <queue>

std::queue<std::string> commands;
commands.push("ARM");            // стати в кінець черги
commands.push("TAKEOFF 20m");
commands.push("LAND");

while (!commands.empty()) {
    std::string cmd = commands.front();   // хто перший?
    commands.pop();                        // забрати його
    std::cout << "виконую: " << cmd << "\n";
}
```

## Стек — як стопка тарілок

```
         push ↓   ↑ pop
          +--------+
          |  Ціль  |  <- top (верхня)
          |  Поле  |
          |  Ліс   |
          |  Міст  |
          |  HOME  |
          +--------+
```

**LIFO** — Last In, First Out. Дрон летить через точки HOME → Міст → Ліс → Поле → Ціль
і запам'ятовує їх у стеку. Щоб повернутися **тим самим шляхом**, знімаємо точки зі стеку —
вони виходять у зворотному порядку: Ціль, Поле, Ліс, Міст, HOME.

```cpp
#include <stack>

std::stack<std::string> path;
path.push("HOME");
path.push("Міст");
path.push("Ліс");

while (!path.empty()) {
    std::cout << path.top() << "\n";   // верхня
    path.pop();                         // зняти
}
// Ліс, Міст, HOME
```

## Порівняння

| | Черга `std::queue` | Стек `std::stack` |
|---|---|---|
| Принцип | перший прийшов — перший вийшов | останній прийшов — перший вийшов |
| Додати | `push(x)` — у кінець | `push(x)` — наверх |
| Подивитись | `front()` — перший | `top()` — верхній |
| Забрати | `pop()` — першого | `pop()` — верхнього |
| Усі операції | O(1) | O(1) |
| Де на дроні | черга команд, черга пакетів радіозв'язку, пошук шляху (урок 8) | повернення назад, «скасувати дію» (Ctrl+Z), перевірка дужок |

> `pop()` нічого не повертає! Спочатку `front()`/`top()` — подивитись, потім `pop()` — забрати.

## Класична задача: перевірка дужок

Чи правильно розставлені дужки в `"speed*(2+[x-1])"`? Ідея зі стеком:

- відкриваюча `(` або `[` → кладемо в стек;
- закриваюча → на вершині стеку має бути **парна** відкриваюча; знімаємо її;
- наприкінці стек має бути порожній.

```
"([)]":   (  -> стек: (
          [  -> стек: ( [
          )  -> на вершині [, а треба ( -> ПОМИЛКА
```

Це вправа 5.3.

## Типові помилки

| Помилка | Що буде |
|---|---|
| `front()` або `top()` на порожній черзі/стеку | програма падає або видає сміття |
| `std::string x = q.pop();` | помилка компіляції: `pop()` нічого не повертає |
| забути `pop()` у циклі `while (!q.empty())` | нескінченний цикл |

## Коротко

- Черга — FIFO: `push`, `front`, `pop`. Для «по порядку надходження».
- Стек — LIFO: `push`, `top`, `pop`. Для «назад», «скасувати», вкладених дужок.
- Перед `front`/`top`/`pop` — завжди перевіряй `empty()`.
