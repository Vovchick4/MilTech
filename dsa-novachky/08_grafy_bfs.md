# Урок 8. Карта як граф і пошук шляху (BFS)

## Що вивчимо

- Що таке граф — на прикладі карти з забороненими зонами.
- Пошук у ширину (BFS) — найкоротший шлях в обхід перешкод.
- Як відновити сам шлях, а не лише його довжину.

## Навіщо дрону

Дрон має долетіти з точки S до точки G, але на карті є заборонені зони (`#`).
Треба знайти **найкоротший** шлях, що їх обходить.

## Карта = граф

**Граф** — це точки (**вершини**) і зв'язки між ними (**ребра**).
На нашій карті:

- вершина — кожна вільна клітинка;
- ребро — між сусідніми клітинками (вгору, вниз, вліво, вправо);
- `#` — клітинка, в яку не можна.

```
S...#.....        S — старт, G — ціль
.##.#.###.        . — вільно
.#..#...#.        # — заборонена зона
.#.##.#.#.
......#..G
```

## Ідея BFS: хвиля від каменя у воді

Кинь камінь у воду — хвиля розходиться колами: спочатку все на відстані 1, потім 2, потім 3...
BFS робить те саме:

1. Старт має відстань 0. Кладемо його в **чергу** (урок 5!).
2. Беремо клітинку з черги. Усім її вільним **ще не відвіданим** сусідам ставимо відстань + 1
   і кладемо їх у чергу.
3. Повторюємо, поки черга не порожня.

Оскільки черга — FIFO, ми обробляємо всі клітинки на відстані 1, потім усі на відстані 2 і т.д.
Тому перша відстань, яку отримує клітинка, — найкоротша.

### Хвиля на нашій карті

Приклад друкує, на якій відстані кожна клітинка (остання цифра числа, щоб влізло в одну позицію):

```
0123#34567        верхній правий кут: 13, 14, 15, 16, 17 кроків
1##4#2###8        (видно лише останню цифру)
2#65#123#9
3#7##0#4#8
456789#567        G — 17 кроків
```

Хвиля обходить стіну `#` знизу: 0 → 1 → 2 → 3 → 4 (вниз), потім вправо 5, 6, 7, 8, 9,
вгору через прохід 10, 11...

## Код BFS

```cpp
struct Cell {
    int row;
    int col;
};

// зсуви до 4 сусідів: вгору, вниз, вліво, вправо
const int DR[4] = {-1, 1, 0, 0};
const int DC[4] = {0, 0, -1, 1};

// dist[r][c] = за скільки кроків дістались; -1 = ще не були
std::vector<std::vector<int>> dist(rows, std::vector<int>(cols, -1));

std::queue<Cell> q;
q.push(start);
dist[start.row][start.col] = 0;

while (!q.empty()) {
    Cell cur = q.front();
    q.pop();
    for (int k = 0; k < 4; k++) {                 // 4 сусіди
        int nr = cur.row + DR[k];
        int nc = cur.col + DC[k];
        if (is_free(map, nr, nc) && dist[nr][nc] == -1) {
            dist[nr][nc] = dist[cur.row][cur.col] + 1;
            parent[nr][nc] = cur;                 // запам'ятали, звідки прийшли
            q.push(Cell{nr, nc});
        }
    }
}
```

Нове тут:

- `std::vector<std::vector<int>>` — **вектор векторів**, тобто таблиця. `dist[r][c]` — рядок r, стовпець c.
  `std::vector<int>(cols, -1)` — рядок з `cols` елементів, кожен = -1.
- `DR` і `DC` — щоб не писати чотири однакові `if` для чотирьох сусідів.
- `is_free` — перевіряє, що клітинка **на карті** і не `#`. Без перевірки меж — вихід за межі масиву!

## Як відновити шлях

`dist` каже лише «скільки кроків». Щоб знати **якими клітинками**, у `parent[r][c]` зберігаємо,
з якої клітинки ми прийшли. Потім ідемо від цілі назад по `parent` до старту:

```
G <- parent(G) <- parent(parent(G)) <- ... <- S
```

Як ланцюжок «хто мене сюди привів». Результат:

```
Найкоротший шлях: 17 кроків
  S...#.....
  *##.#.###.
  *#..#***#.
  *#.##*#*#.
  ******#**G
```

## Складність

Кожна клітинка потрапляє в чергу **один раз** (бо перевіряємо `dist == -1`), і в кожної 4 сусіди.
Тому BFS — **O(кількість клітинок)**. Карта 1000 × 1000 — мільйон кроків, це швидко.

## Типові помилки

| Помилка | Що буде |
|---|---|
| немає перевірки `dist[nr][nc] == -1` | клітинки потрапляють у чергу знову і знову — нескінченний цикл |
| перевірка меж після звертання `map[nr][nc]` | вихід за межі масиву |
| стек замість черги | знайде **якийсь** шлях, але не найкоротший |
| ставити відстань при виході з черги, а не при вході | клітинка встигне потрапити в чергу кілька разів |

## Що далі

BFS вважає всі кроки однаковими. А якщо в деяких зонах сильний вітер і літати там «дорожче»?
Тоді потрібні алгоритми **Dijkstra** і **A*** — вони в модулі рівня 2. Ідея та сама, тільки замість
звичайної черги — «черга з пріоритетом».

## Коротко

- Карта — граф: клітинки — вершини, сусідство — ребра.
- BFS — «хвиля» з черги; дає найкоротший шлях за кількістю кроків.
- `dist` — скільки кроків, `parent` — звідки прийшли (щоб намалювати шлях).
