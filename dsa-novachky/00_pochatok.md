# Урок 0. З чого почати

## Що таке алгоритм

**Алгоритм** — це точна послідовність кроків, щоб розв'язати задачу.

Приклад з життя — «знайти найвищу людину в кімнаті»:

1. Запам'ятай першу людину як «найвищу поки що».
2. Подивись на наступну. Якщо вона вища — тепер вона «найвища поки що».
3. Повторюй, поки не переглянеш усіх.
4. Хто лишився «найвищим поки що» — відповідь.

Це вже алгоритм. У уроці 2 ми напишемо його на C++ — для висоти дрона.

## Що таке структура даних

**Структура даних** — це спосіб *зберігати* дані, щоб з ними було зручно і швидко працювати.

| Структура | Як у житті | Урок |
|---|---|---|
| масив (`std::vector`) | ряд пронумерованих шафок | 2 |
| стек (`std::stack`) | стопка тарілок: беремо верхню | 5 |
| черга (`std::queue`) | черга в магазині: хто перший прийшов — перший пішов | 5 |
| кільцевий буфер | годинник: після 12 знову 1 | 6 |
| словник (`std::map`) | телефонна книга: ім'я → номер | 7 |
| граф | карта міст і доріг між ними | 8 |

## Навіщо це програмісту дронів

Автопілот дрона за **одну секунду 400 разів** читає датчики, рахує, куди летіти, і керує моторами.
На все — 2.5 мілісекунди. Якщо обрати повільний алгоритм або незручну структуру даних —
програма не встигне, і дрон почне смикатись. Тому вміти обрати правильний спосіб — дуже важливо.

## Як запускати код з модуля

Тобі потрібен компілятор `g++`. Перевір — **WSL Ubuntu / Linux / macOS terminal:**

```bash
g++ --version
```

Якщо команди немає — **WSL Ubuntu / Linux:** `sudo apt install g++`, **macOS:** `xcode-select --install`.

Запуск будь-якого файлу:

```bash
g++ -std=c++17 -Wall example.cpp -o example
./example
```

| Частина | Що означає |
|---|---|
| `g++` | компілятор: перетворює текст програми на програму, яку можна запустити |
| `-std=c++17` | версія мови C++ |
| `-Wall` | показувати попередження (warnings) — вони часто підказують помилку |
| `example.cpp` | твій файл |
| `-o example` | як назвати готову програму |
| `./example` | запустити її |

## Як влаштовані вправи

У кожному `exercises.cpp` є функції з `// TODO`. Наприклад:

```cpp
// 2.1 Найменше значення. Масив не порожній.
int min_value(const std::vector<int>& values)
{
    // TODO
    (void)values;    // <- цей рядок можна видалити, коли напишеш код
    return 0;
}
```

Внизу файлу — перевірки:

```
[OK]   2.1 min_value
[FAIL] 2.2 count_above
...
Помилок: 6
```

Твоя мета — `Помилок: 0`. Перевірки змінювати не можна — тільки функції.

> `(void)values;` — це лише спосіб сказати компілятору «я знаю, що змінна поки не використовується»,
> щоб він не показував попередження. Коли напишеш свій код — видали цей рядок.

## Нагадування з C++, яке знадобиться

### `std::vector` — масив, що вміє рости

```cpp
std::vector<double> heights = {0.0, 2.5, 6.0};
heights.push_back(11.2);          // додати в кінець
double first = heights[0];        // елемент за номером (нумерація з 0!)
int n = (int)heights.size();      // скільки елементів
```

`(int)` перед `heights.size()` — перетворення в `int`. `size()` повертає беззнакове число,
і порівнювати його з `int i` компілятор не любить (буде попередження).

### Передача у функцію: `const std::vector<int>&`

```cpp
int sum(const std::vector<int>& values)
```

- `&` — передати **посилання**, тобто сам вектор, а не його копію. Копіювати мільйон чисел — повільно.
- `const` — функція обіцяє вектор **не змінювати**.

Якщо функція **має** змінити вектор (наприклад, відсортувати) — пишемо без `const`:

```cpp
void sort_it(std::vector<int>& values)
```

### `struct` — кілька значень разом

```cpp
struct Drone {
    std::string name;
    int battery;
};

Drone d = {"Alpha", 76};
std::cout << d.name << " " << d.battery << "\n";
```

### `auto` у циклі (зустрінеться в уроці 7)

```cpp
for (const auto& item : params) { ... }
```

`auto` — «компілятор, визнач тип сам». Тут це зручно, бо справжній тип довгий.
`for (... : params)` — пройти по всіх елементах, без індексу.

## Коротко

- Алгоритм — точні кроки розв'язання задачі. Структура даних — як зберігати дані.
- На дроні важлива швидкість: усе треба встигати за мілісекунди.
- Компілюємо: `g++ -std=c++17 -Wall файл.cpp -o програма`, запускаємо: `./програма`.
- У вправах пишемо код там, де `// TODO`, поки не буде `Помилок: 0`.
