# Урок 3. Сортування

## Що вивчимо

- Як працюють три прості сортування: бульбашкою, вибором, вставками.
- Готове `std::sort` — і як сортувати свої структури (дрони за зарядом).

## Навіщо дрону

- Відсортувати дрони за зарядом — кого першим на зарядку.
- Знайти медіану висоти (середнє за порядком значення) — потрібен відсортований масив.
- Бінарний пошук (урок 4) працює **тільки** на відсортованих даних.

## 1. Бульбашка: міняємо сусідів

Йдемо зліва направо і порівнюємо **сусідів**. Якщо лівий більший за правого — міняємо їх місцями.
Після першого проходу найбільше число «спливає» в самий кінець — як бульбашка у воді.

Приклад `{64, 25, 12, 22, 11}`, перший прохід:

```
[64, 25, 12, 22, 11]   64 > 25 -> міняємо
[25, 64, 12, 22, 11]   64 > 12 -> міняємо
[25, 12, 64, 22, 11]   64 > 22 -> міняємо
[25, 12, 22, 64, 11]   64 > 11 -> міняємо
[25, 12, 22, 11, 64]   64 на своєму місці!
```

```cpp
for (int pass = 0; pass < n - 1; pass++) {
    for (int i = 0; i < n - 1 - pass; i++) {   // кінець уже відсортований
        if (v[i] > v[i + 1]) {
            std::swap(v[i], v[i + 1]);          // поміняти місцями
        }
    }
}
```

`std::swap(a, b)` — поміняти значення двох змінних (з `<algorithm>`).

## 2. Вибір: знайти найменший і поставити на місце

На кожному кроці шукаємо **найменший** серед ще не відсортованих і ставимо його на чергове місце зліва.

```
[64, 25, 12, 22, 11]   найменший 11 -> на місце 0
[11, 25, 12, 22, 64]   серед [25,12,22,64] найменший 12 -> на місце 1
[11, 12, 25, 22, 64]   серед [25,22,64] найменший 22 -> на місце 2
[11, 12, 22, 25, 64]   готово
```

## 3. Вставки: як карти в руці

Береш карти по одній і **вставляєш** кожну на правильне місце серед тих, що вже в руці.

```
рука: [5]            беремо 2 -> менша за 5 -> [2, 5]
рука: [2, 5]         беремо 4 -> між 2 і 5   -> [2, 4, 5]
рука: [2, 4, 5]      беремо 6 -> в кінець    -> [2, 4, 5, 6]
рука: [2, 4, 5, 6]   беремо 1 -> на початок  -> [1, 2, 4, 5, 6]
```

У коді «вставити» = зсунути всі більші елементи на одну позицію вправо, щоб звільнити місце.
Це вправа 3.3 — спробуй сам!

## Наскільки вони швидкі?

Усі три прості сортування — **O(n²)**: цикл у циклі.
На 1000 елементах — нормально. На мільйоні — дуже повільно.

`std::sort` зі стандартної бібліотеки — **O(n log n)**, у тисячі разів швидше на великих даних.
У реальному коді завжди використовуй `std::sort`. Прості сортування ми пишемо, щоб **зрозуміти** ідею.

## `std::sort`

```cpp
#include <algorithm>

std::vector<int> c = {5, 3, 9, 1, 7, 3};
std::sort(c.begin(), c.end());   // від початку до кінця
// c = {1, 3, 3, 5, 7, 9}
```

`c.begin()` і `c.end()` — «звідки і докуди сортувати». Поки що просто запам'ятай цей запис.

### Сортування структур

Як `std::sort` знатиме, як порівнювати дрони? Ми даємо йому **функцію-порівняння**:
«чи має `a` стояти раніше за `b`?»

```cpp
struct Drone {
    std::string name;
    int battery;
};

bool less_battery(const Drone& a, const Drone& b)
{
    return a.battery < b.battery;    // менший заряд — раніше
}

std::sort(fleet.begin(), fleet.end(), less_battery);  // передаємо ім'я функції, без ()
```

## Типові помилки

| Помилка | Що буде |
|---|---|
| `i < n` замість `i < n - 1` у бульбашці | `v[i + 1]` вийде за межі масиву |
| `std::sort(fleet.begin(), fleet.end(), less_battery())` | помилка компіляції — ім'я функції пишемо **без** дужок |
| функція-порівняння повертає `<=` | `std::sort` може зламатися — тільки строго `<` або `>` |
| сортувати `const`-вектор | помилка компіляції — зроби копію |

## Перевір себе

1. Скільки проходів у найгіршому випадку робить бульбашка для 5 елементів?
<details><summary>Відповідь</summary>4 (n - 1). Після кожного проходу ще один елемент стає на своє місце.</details>

2. Чому для медіани масив треба відсортувати?
<details><summary>Відповідь</summary>Медіана — це середній елемент **за порядком величини**. Без сортування середній за позицією може бути будь-яким.</details>

3. Коли просте сортування підійде, а коли треба `std::sort`?
<details><summary>Відповідь</summary>Для навчання і крихітних масивів — підійде. У реальному коді й на великих даних — завжди `std::sort` (O(n log n) замість O(n²)).</details>

## Коротко

- Бульбашка — міняємо сусідів; вибір — шукаємо найменший; вставки — як карти в руці. Усі O(n²).
- `std::sort(v.begin(), v.end())` — швидко, O(n log n).
- Для своїх структур — функція-порівняння «чи має a стояти раніше за b?».
