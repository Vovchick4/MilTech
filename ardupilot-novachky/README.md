# ArduPilot для новачків: симулятор дрона + C++

У цьому модулі ти запустиш дрон у комп'ютері (симулятор), полетаєш ним «руками» з
наземної станції, а потім напишеш на C++ програми, які самі піднімуть дрон, проведуть його
маршрутом і посадять.

Потрібно знати основи C++: змінні, `if`, цикли, функції, `std::vector`, `struct`.
Справжній дрон не потрібен — усе працює в комп'ютері.

## Як проходити

1. Читай урок повністю, перш ніж щось запускати.
2. Роби кроки по черзі. Після кожного кроку в тексті написано **«Що маєш побачити»** — порівняй.
3. Не вийшло — дивись [problemy.md](problemy.md). Не допомогло — клич викладача і покажи,
   що написано в терміналі.
4. Вправи в кінці уроку — обов'язкові. Саме на них ти вчишся.

## Що в папці `code/`

```
code/
├── lesson04_connect.cpp        <- програма уроку 4
├── lesson05_telemetry.cpp      <- програма уроку 5
├── lesson06_takeoff_land.cpp
├── lesson07_goto_point.cpp
├── lesson08_route.cpp
├── lesson10_final_task.cpp     <- підсумкове завдання (з TODO)
├── lua/                        <- скрипти для уроку 9
├── scripts/
│   ├── install_ubuntu.sh       <- встановити все (урок 1)
│   ├── check.sh                <- перевірити, чи все встановлено
│   ├── run_sitl.sh             <- запустити симулятор
│   └── run.sh                  <- зібрати і запустити програму уроку
└── CMakeLists.txt              <- опис проєкту для збірки (змінювати не треба)
```

## Три команди, які знадобляться весь час

```bash
./scripts/run_sitl.sh                    # термінал 1: запустити симулятор
./scripts/run.sh lesson05_telemetry      # термінал 2: зібрати і запустити програму
bash scripts/check.sh                    # перевірити, чи все встановлено
```
