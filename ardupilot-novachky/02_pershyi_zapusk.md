# Урок 2. Перший запуск симулятора

## Що зробимо

- Запустимо SITL — «дрон у комп'ютері».
- Підключимо до нього Mission Planner (або QGroundControl).
- Розберемося, що показує екран наземної станції.

## Крок 1. Запустити SITL

**Ubuntu / Термінал macOS**, у папці `code`:

```bash
./scripts/run_sitl.sh
```

**Що маєш побачити:**

```
bind port 5760 for SERIAL0
SERIAL0 on TCP port 5760
Waiting for connection ....
```

`Waiting for connection` — симулятор **чекає**, поки до нього підключиться наземна станція.
Поки ніхто не підключився — дрон «спить». Це нормально.

> Не закривай це вікно! Поки воно відкрите — дрон «живий». Зупинити симулятор — `Ctrl+C`.

## Крок 2. Підключити наземну станцію

### Mission Planner (Windows)

1. Запусти Mission Planner.
2. Праворуч угорі є випадаючий список (там написано `COM...` або `AUTO`) — обери **TCP**.
3. Натисни **CONNECT**.
4. Host: `127.0.0.1` → OK. Port: `5760` → OK.

> `127.0.0.1` означає «цей самий комп'ютер». WSL і Windows вміють так «бачити» одне одного.

### QGroundControl (macOS / Linux / Windows)

1. Натисни на логотип Q угорі ліворуч → **Application Settings** → **Comm Links** → **Add**.
2. Name: `SITL`, Type: **TCP**, Server Address: `127.0.0.1`, Port: `5760` → **OK**.
3. Обери `SITL` у списку → **Connect**.

**Що маєш побачити:** у терміналі SITL з'явиться `Connection on serial port 5760`,
а в наземній станції — завантаження параметрів (смужка прогресу), потім карта з дроном.

## Крок 3. Що на екрані (Mission Planner, вкладка DATA)

```
+---------------------------+---------------------------------------+
|  ШТУЧНИЙ ГОРИЗОНТ (HUD)   |                                       |
|  - нахил дрона            |              КАРТА                    |
|  - висота, швидкість      |      дрон (червоний значок)           |
|  - DISARMED / ARMED       |      над Канберрою, Австралія         |
|  - режим (Stabilize)      |                                       |
|  - GPS, батарея           |                                       |
+---------------------------+                                       |
|  вкладки: Quick, Actions, |                                       |
|  Messages ...             |                                       |
+---------------------------+---------------------------------------+
```

Знайди на екрані:

| Що | Де | Яке значення зараз |
|---|---|---|
| Стан моторів | HUD, великими літерами | **DISARMED** |
| Режим польоту | HUD, внизу | **Stabilize** |
| GPS | HUD | `3D Fix` (або `GPS: 3D Fix`) |
| Заряд батареї | HUD | ~12.6 В, 100% |
| Де дрон | карта | Канберра, Австралія — «дім» симулятора за замовчуванням |
| Повідомлення автопілота | вкладка **Messages** | `EKF3 IMU0 is using GPS` тощо |

Почекай 30–60 секунд. Автопілот «прогрівається»: шукає GPS, налаштовує датчики.
Коли все готово, у HUD з'явиться **Ready to Arm** (або зникнуть червоні попередження).

## Крок 4. Зупинити все

- У Mission Planner — **DISCONNECT**.
- У терміналі SITL — `Ctrl+C`.

## Запам'ятай порядок

```
1. SITL (термінал)  ->  2. Mission Planner / QGC на 5760  ->  3. (з уроку 4) твоя програма на 5762
```

SITL першим, бо він «сервер», до якого всі підключаються.

## Корисні варіанти запуску

| Команда | Що робить |
|---|---|
| `./scripts/run_sitl.sh` | звичайний запуск |
| `SPEEDUP=5 ./scripts/run_sitl.sh` | симуляція в 5 разів швидша (для довгих польотів) |
| `WIPE=1 ./scripts/run_sitl.sh` | скинути всі налаштування дрона до заводських (якщо щось зламав) |

## Вправа

1. Запусти SITL і підключи наземну станцію.
2. Запиши: координати дому (наведи мишку на дрон на карті), напругу батареї, режим.
3. Відкрий вкладку **Messages** — випиши 3 повідомлення від автопілота.
4. Зупини все і запусти знову, але вже без підглядання в цей урок.

## Коротко

- `./scripts/run_sitl.sh` — запустити дрон. Не закривати вікно!
- Наземна станція: TCP, `127.0.0.1`, порт `5760`.
- Після старту чекаємо 30–60 с, поки автопілот готовий.
