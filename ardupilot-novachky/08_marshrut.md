# Урок 8. Маршрут з кількох точок

## Що вивчимо

- Як описати маршрут списком точок: `struct` + `std::vector`.
- Як облетіти всі точки циклом `for`.
- Як показувати прогрес і задавати швидкість.

## Ідея

В уроці 7 ми летіли в одну точку. Маршрут — це просто **список точок**, і ми летимо в кожну по черзі.
Точки зручно задавати не в градусах, а в метрах від дому — так легше уявити:

```
                 P1 (200, 0) -----> P2 (200, 200)
                  ^                      |
     північ ^     |                      |
            |     |                      v
            +-> схід                     
                ДІМ (0, 0) <------- P3 (0, 200)
```

## Опис маршруту

```cpp
struct Waypoint {
    std::string name;
    double north_m;   // на скільки метрів північніше дому
    double east_m;    // на скільки метрів східніше дому
};

std::vector<Waypoint> route = {
    {"P1 (північ)",       SIDE_M, 0},
    {"P2 (північ-схід)",  SIDE_M, SIDE_M},
    {"P3 (схід)",         0,      SIDE_M},
    {"ДІМ",               0,      0},
};
```

Хочеш інший маршрут — просто зміни список. Решта коду не змінюється.

## Облетіти всі точки

```cpp
for (int i = 0; i < (int)route.size(); i++) {
    double lat = home.latitude_deg + route[i].north_m / METERS_PER_DEGREE;
    double lon = home.longitude_deg + route[i].east_m / (METERS_PER_DEGREE * std::cos(...));
    fly_to(action, telemetry, route[i].name, lat, lon, altitude_amsl);
}
```

Для кожної точки: метри → градуси (урок 7) → `fly_to`.

## Прогрес у відсотках

```cpp
double total = відстань на початку;
double left  = скільки лишилось зараз;
int percent = (int)(100.0 * (total - left) / total);
```

Друкуємо раз на 5 секунд (`if (seconds % 5 == 0)`), щоб не засмічувати екран. `%` — остача від ділення:
`seconds % 5 == 0` правда для 0, 5, 10, 15...

## Швидкість

```cpp
action.set_current_speed(SPEED_M_S);   // 10 м/с = 36 км/год
```

Задаємо **після** зльоту.

## Великий маршрут

Зміни `SIDE_M` на `2500` — це квадрат 2.5 × 2.5 км, маршрут **10 км**. При 10 м/с — це ~17 хвилин.
Щоб не чекати, прискор симуляцію:

```bash
SPEEDUP=10 ./scripts/run_sitl.sh
```

> Відсотки й секунди в програмі рахуються в «справжньому» часі, тому з прискоренням дрон
> просто долітає швидше. Код міняти не треба.

## Вправи

1. Трикутник: дім → (300, 0) → (0, 300) → дім.
2. «Змійка» з 6 точок: (100,0) → (100,100) → (200,100) → (200,200) → (300,200) → дім.
3. Додай у `Waypoint` поле `float altitude_m` — і нехай кожна точка має свою висоту.
4. Після кожної точки друкуй заряд батареї. Скільки відсотків «з'їдає» 200 м?
5. Наприкінці надрукуй, скільки часу зайняв увесь маршрут і яку відстань пролетіли.
6. (★) Зроби маршрут 10 км (`SIDE_M = 2500`) з `SPEEDUP=10`. Скріншот траєкторії з Mission Planner.

## Коротко

- Маршрут = `std::vector<Waypoint>`; точки в метрах від дому.
- Цикл `for` по точках: метри → градуси → `fly_to`.
- `set_current_speed` — швидкість; `SPEEDUP` у SITL — щоб довгі маршрути не тривали годину.
