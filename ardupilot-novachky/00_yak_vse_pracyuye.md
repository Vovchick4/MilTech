# Урок 0. Як усе влаштовано

## Що вивчимо

- З яких частин складається «дрон у комп'ютері».
- Хто з ким і якою «мовою» розмовляє.
- Головні слова: ARM, режим польоту, телеметрія.

## Справжній дрон

```
   пульт оператора                      дрон
  +----------------+    радіо     +-------------------------+
  | ноутбук з      | <----------> | польотний контролер     |
  | Mission Planner|              | (маленька плата-«мозок»)|
  +----------------+              |  на ній — ArduPilot     |
                                  +-----------+-------------+
                                              |
                                   мотори, GPS, датчики, батарея
```

- **Польотний контролер** — маленький комп'ютер на дроні. Він 400 разів на секунду читає датчики
  і керує моторами, щоб дрон не впав.
- **ArduPilot** — програма (прошивка), яка працює на польотному контролері. Безкоштовна,
  з відкритим кодом, на C++. Нею літають тисячі дронів, літаків, човнів.
- **Наземна станція** (GCS, Ground Control Station) — програма на ноутбуці: карта, де зараз дрон,
  висота, заряд, кнопки «злетіти», «сісти». Ми використаємо **Mission Planner** (Windows)
  або **QGroundControl** (Windows, Mac, Linux).

## Дрон у комп'ютері: SITL

Купувати і розбивати дрони під час навчання — дорого. Тому є **SITL** (Software In The Loop) —
симулятор:

```
  +--------------------- твій комп'ютер ----------------------+
  |                                                           |
  |   SITL = справжній ArduPilot + «віртуальний» дрон         |
  |   (мотори, GPS, вітер, батарея — усе змодельовано)        |
  |                                                           |
  +-----------------------------------------------------------+
```

Головне: **код ArduPilot у симуляторі той самий, що на справжньому дроні.**
Якщо твоя програма працює з SITL — вона працюватиме і з реальним дроном.

## Мова, якою говорить дрон: MAVLink

Дрон і наземна станція обмінюються короткими повідомленнями: «я тут, висота 20 м»,
«злітай», «заряд 76%». Ця «мова» називається **MAVLink**. Писати MAVLink-повідомлення вручну
складно, тому для C++ є бібліотека **MAVSDK** — вона «перекладає»:

```
твій C++ код:   action.takeoff();
        |
      MAVSDK  (перекладач)
        |
MAVLink:        COMMAND_LONG, command = 22 (TAKEOFF) ...
        |
     ArduPilot: «Зрозумів, злітаю»
```

## Як це все з'єднано в нашому модулі

SITL відкриває кілька «розеток» (мережевих портів). До кожної можна підключити **одну** програму:

```
                 +--------------------+
                 |   SITL (дрон)      |
                 |                    |
  Mission   <----| порт 5760          |
  Planner        |                    |
                 |                    |
  твоя C++  <----| порт 5762          |
  програма       |                    |
                 +--------------------+
```

Mission Planner — на **5760**, твоя програма — на **5762**. Обидві бачать один і той самий дрон:
програма командує, а в Mission Planner видно, що відбувається.

> Якщо дві програми спробують підключитися до однієї «розетки» — друга не підключиться.

## Головні слова

| Слово | Що означає |
|---|---|
| **ARM** | «увімкнути мотори». До ARM дрон не може злетіти — це захист |
| **DISARM** | вимкнути мотори. Після посадки ArduPilot робить це сам |
| **Режим польоту** | хто і як керує дроном (див. нижче) |
| **Телеметрія** | дані від дрона: висота, координати, швидкість, заряд |
| **Home (дім)** | точка, з якої дрон злетів. Туди він повертається в режимі RTL |
| **Waypoint** | точка маршруту |

### Режими польоту (ArduCopter)

| Режим | Хто керує | Коли |
|---|---|---|
| **STABILIZE** | пілот з пульта | режим за замовчуванням після старту |
| **GUIDED** | програма або Mission Planner: «лети туди» | **наш головний режим** |
| **AUTO** | дрон сам летить завантаженою місією | місії |
| **LAND** | дрон сідає там, де він є | посадка |
| **RTL** | Return To Launch: летить додому і сідає | повернення |

> MAVSDK показує режим GUIDED як `Offboard`, а STABILIZE як `Stabilized`. Це той самий режим,
> просто інші назви в бібліотеці.

## Перевір себе

1. Чим SITL відрізняється від справжнього дрона з погляду коду ArduPilot?
<details><summary>Відповідь</summary>Нічим — це той самий код. Різниця лише в тому, що мотори, GPS і датчики змодельовані.</details>

2. Навіщо MAVSDK, якщо є MAVLink?
<details><summary>Відповідь</summary>MAVLink — «мова» повідомлень, писати її вручну складно. MAVSDK дає прості функції: arm(), takeoff(), position().</details>

3. Чому твоя програма підключається до порту 5762, а не 5760?
<details><summary>Відповідь</summary>5760 вже зайнятий Mission Planner, а одна «розетка» — одна програма.</details>

## Коротко

- ArduPilot — «мозок» дрона. SITL — той самий ArduPilot з віртуальним дроном.
- Mission Planner / QGroundControl — пульт на екрані. MAVLink — мова. MAVSDK — перекладач для C++.
- SITL: порт 5760 — для Mission Planner, 5762 — для твоєї програми.
