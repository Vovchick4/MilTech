# Урок 9. Параметри і Lua — змінюємо поведінку самого автопілота

## Що вивчимо

- Що таке **параметри** ArduPilot і як їх змінювати в Mission Planner.
- Як симулювати вітер.
- Як написати маленький **Lua-скрипт**, що працює всередині автопілота.

До цього наша програма **просила** дрон щось зробити ззовні. Тепер ми змінимо, **як поводиться
сам автопілот**.

## Частина 1. Параметри

ArduPilot має понад тисячу налаштувань — **параметрів**. Наприклад:

| Параметр | Що задає | За замовчуванням |
|---|---|---|
| `WPNAV_SPEED` | швидкість польоту до точки, **см/с** | 1000 (= 10 м/с) |
| `RTL_ALT` | на якій висоті летіти додому в RTL, **см** | 1500 (= 15 м) |
| `SIM_WIND_SPD` | сила вітру в симуляторі, м/с (тільки SITL) | 0 |
| `SIM_WIND_DIR` | звідки дме вітер, градуси (тільки SITL) | 180 |
| `SCR_ENABLE` | увімкнути Lua-скрипти | 0 |

> Зверни увагу на одиниці: багато параметрів у **сантиметрах**. 1500 — це 15 м, а не 1500 м!

### Як змінити (Mission Planner)

1. Вкладка **CONFIG** → **Full Parameter List**.
2. Справа пошук: введи `RTL_ALT`.
3. Зміни значення в колонці **Value** → кнопка **Write Params**.

**QGroundControl:** логотип Q → **Vehicle Setup** → **Parameters** → пошук → клікнути значення → Save.

Параметри **зберігаються** в пам'яті дрона і після перезапуску SITL. Скинути все — `WIPE=1 ./scripts/run_sitl.sh`.

### Експеримент 1: RTL на іншій висоті

1. Постав `RTL_ALT = 4000` (40 м).
2. У Mission Planner: Guided → Arm → Takeoff на **10 м** → **Fly To Here** у точку метрів за 200 від дому.
3. Коли долетить — режим **RTL**. Що дрон робить спершу? Яку висоту показує HUD?
4. Повтори з `RTL_ALT = 1500`. А якщо зробити RTL, коли дрон висить просто над домом?

> Якщо дрон уже над домом, RTL одразу сідає — підніматися немає сенсу.

### Експеримент 2: вітер

1. `SIM_WIND_SPD = 10`, `SIM_WIND_DIR = 90` (вітер зі сходу).
2. Запусти `lesson08_route`.
3. Порівняй час до кожної точки з польотом без вітру. Куди нахиляється дрон у HUD?
4. Поверни `SIM_WIND_SPD = 0`.

## Частина 2. Lua-скрипт

**Lua** — проста мова, скрипти на якій ArduPilot виконує **прямо на дроні**, без перезбирання прошивки.
Так додають власну логіку: попередження, перевірки, автоматичні дії.

### Крок 1. Увімкнути скрипти

`SCR_ENABLE = 1` → **Write Params** → перезапусти SITL (`Ctrl+C` і `./scripts/run_sitl.sh`).

### Крок 2. Покласти скрипт

**Ubuntu:**

```bash
mkdir -p ~/ardupilot/scripts
cp lua/hello_altitude.lua ~/ardupilot/scripts/
```

Перезапусти SITL ще раз.

### Крок 3. Подивитись результат

Mission Planner → вкладка **Messages**:

```
hello_altitude started
Hello! Alt -0.0 m, mode 0
Hello! Alt -0.0 m, mode 0
```

Злети з Mission Planner — висота в повідомленнях зміниться.

### Розбір скрипту `hello_altitude.lua`

```lua
function update()
  local loc  = ahrs:get_location()   -- де ми зараз
  local home = ahrs:get_home()       -- де дім

  if loc and home and ahrs:home_is_set() then
    local altitude = (loc:alt() - home:alt()) / 100        -- см -> м
    gcs:send_text(6, string.format("Hello! Alt %.1f m, mode %d", altitude, vehicle:get_mode()))
  end

  return update, 5000    -- викликати update() знову через 5000 мс
end

return update, 1000      -- перший запуск через 1 с
```

| Lua | Схоже на C++ |
|---|---|
| `local x = 5` | `auto x = 5;` |
| `if a and b then ... end` | `if (a && b) { ... }` |
| `-- коментар` | `// коментар` |
| `function f() ... end` | `void f() { ... }` |

Головна ідея: функція `update()` повертає **саму себе і час** — «виклич мене знову через 5 секунд».
Так скрипт працює весь політ, не блокуючи автопілот.

> Тексти — **англійською**. Повідомлення автопілота обмежені 50 байтами, а кирилиця
> в Mission Planner показується «кракозябрами».

### Номери режимів

`vehicle:get_mode()` повертає **число**: 0 = STABILIZE, 4 = GUIDED, 5 = LOITER, 6 = RTL, 9 = LAND.

### Крок 4. Скрипт, що рятує дрон

`lua/distance_guard.lua` — «віртуальна прив'язка»: якщо дрон відлетів від дому далі ніж `MAX_DIST_M`,
скрипт сам вмикає RTL. Встанови його так само (крок 2), постав у ньому `MAX_DIST_M = 100`
і запусти `lesson08_route`. Дрон має повернутися додому, не закінчивши квадрат, а в Messages —
`LUA: 106m > 100m -> RTL`.

## Вправи

1. Зміни `WPNAV_SPEED` на 500 (5 м/с) і на 2000 (20 м/с). Як змінюється час маршруту з уроку 8?
2. У `hello_altitude.lua` друкуй ще й відстань до дому: `loc:get_distance(home)`.
3. Нехай `hello_altitude.lua` пише повідомлення не кожні 5, а кожні 2 секунди.
4. (★) Напиши скрипт, який пише `"HIGH!"`, якщо висота більша за 40 м.

## Коротко

- Параметри — налаштування автопілота. Міняються в Full Parameter List. Обережно з одиницями (см!).
- `SIM_WIND_*` — вітер у симуляторі.
- Lua-скрипти працюють на дроні: `SCR_ENABLE = 1`, файл у `~/ardupilot/scripts/`, перезапуск.
- Скрипт — функція `update()`, що повертає «виклич мене через N мс».
