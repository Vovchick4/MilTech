# Урок 7. Політ до точки

## Що вивчимо

- Що таке широта і довгота і як перевести «100 м на північ» у градуси.
- Як порахувати відстань між двома точками.
- Команду `goto_location` і чому їй потрібна висота «над морем».

## Координати: широта і довгота

Будь-яке місце на Землі — два числа:

| | Що показує | Канберра (дім SITL) |
|---|---|---|
| **Широта** (latitude, lat) | північ / південь, від -90 до 90 | -35.363262 |
| **Довгота** (longitude, lon) | схід / захід, від -180 до 180 | 149.165237 |

Мінус у широті — південна півкуля.

### Метри → градуси

**1 градус широти ≈ 111 320 м** — скрізь на Землі. Тому:

```
100 м на північ = 100 / 111320 ≈ 0.000898 градуса широти
```

```cpp
double north_meters_to_degrees(double meters)
{
    return meters / METERS_PER_DEGREE;   // 111320
}
```

**Градус довготи** коротшає, чим далі від екватора (меридіани сходяться на полюсах).
Тому ділимо ще й на `cos(широти)`:

```cpp
double east_meters_to_degrees(double meters, double latitude_deg)
{
    double latitude_rad = latitude_deg * M_PI / 180.0;   // cos() хоче радіани
    return meters / (METERS_PER_DEGREE * std::cos(latitude_rad));
}
```

| Де | 1° довготи |
|---|---|
| екватор | 111 км |
| Київ (50°) | 71 км |
| Канберра (-35°) | 91 км |

### Відстань між точками

Для коротких відстаней (кілька кілометрів) Землю можна вважати пласкою.
Переводимо різницю координат у метри і — **теорема Піфагора**:

```
              B
             /|
   відстань / | на північ
           /  |
          A---+
         на схід

відстань = √(північ² + схід²)
```

```cpp
double distance_m(double lat1, double lon1, double lat2, double lon2)
{
    double north = (lat2 - lat1) * METERS_PER_DEGREE;
    double east = (lon2 - lon1) * METERS_PER_DEGREE * std::cos(lat1 * M_PI / 180.0);
    return std::sqrt(north * north + east * east);
}
```

## Команда goto_location

```cpp
action.goto_location(lat, lon, altitude_amsl, NAN);
```

| Параметр | Що це |
|---|---|
| `lat`, `lon` | куди летіти |
| `altitude_amsl` | висота **над рівнем моря** (AMSL — Above Mean Sea Level) |
| `NAN` | курс (куди «дивитись» носом). `NAN` = «не важливо» |

Чому над рівнем моря? Так влаштована команда в MAVLink. Ми хочемо 20 м над землею, тому:

```cpp
float altitude_amsl = home.absolute_altitude_m + ALTITUDE_M;   // 584 + 20 = 604 м
```

> Якщо помилково передати `20` — це «20 м над морем», а земля в Канберрі на висоті 584 м.
> Тобто ціль **під землею**: дрон почне знижуватись прямо до землі. Дуже небезпечна помилка!

`goto_location` теж лише **приймає** команду. Чекаємо, поки долетимо — функція `fly_to`:

```cpp
while (true) {
    double left = distance_m(now.latitude_deg, now.longitude_deg, lat, lon);
    if (left < ARRIVED_RADIUS_M) {   // ближче 5 м — долетіли
        break;
    }
    wait_seconds(1);
}
```

Чому не `left == 0`? Дрон ніколи не зупиниться **точно** в точці (вітер, шум GPS).
Тому кажемо «долетіли, якщо ближче 5 метрів».

## Коротко

- 1° широти ≈ 111 320 м. Для довготи ще ділимо на `cos(широти)`.
- Відстань на коротких дистанціях — теорема Піфагора.
- `goto_location` хоче висоту **над морем**: `home.absolute_altitude_m + потрібна висота`.
- «Долетіли» = ближче за кілька метрів, а не точно 0.
